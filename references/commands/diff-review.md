# Diff Review

PR diff specialized review.

## Checklist

### Change Scope
- Is the change too large
- Can it be split
- Are related files modified together

### Code Quality
- Follows project conventions
- Test coverage
- Comment completeness

### Security
- No sensitive information leaked
- Dependency security
- Input validation

### Performance
- No obvious performance issues
- Resource release

### Maintainability
- Code readability
- Clear naming
- No duplicate code
