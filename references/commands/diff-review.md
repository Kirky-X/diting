# Diff Review

PR diff-specific review.

## Checklist

### Change Scope
- Is the change too large
- Can it be split
- Related files modified together

### Code Quality
- Follows project conventions
- Test coverage
- Comment completeness

### Security
- No sensitive information leakage
- Dependency security
- Input validation

### Performance
- No obvious performance issues
- Resource cleanup

### Maintainability
- Code readability
- Clear naming
- No duplicate code
