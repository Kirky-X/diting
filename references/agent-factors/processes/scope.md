# F10 — Small, Focused Agents (reference — no static detection)

**Principle**: Build small agents that do one thing well (~3-10 steps, max ~20),
not monoliths. An agent is one building block, not the whole system.

## Why reference only
"Small/focused" is a semantic judgment; the original is narrative with no code
markers. Do NOT emit findings.

## Guidance (when asked)
- cap agent steps (~3-10, max 20); split monoliths
- keep each agent to a single domain
- widen scope cautiously as LLM capability grows
